# 🛒 TechShop – E-Commerce Website

## 📌 Project Overview
**TechShop** is a fully responsive e-commerce frontend website built using **HTML**, **CSS**, and **JavaScript**.  
It simulates an online tech store showcasing electronic gadgets with an interactive and modern user interface.  

The project demonstrates **UI/UX design**, **responsive layout**, and **frontend interactivity** without any backend integration.  

---

## 🧱 Project Structure
TECHSHOP-WEBSITE/
├── index.html # Main HTML page
├── styles.css # CSS styling
├── script.js # JavaScript logic (interactivity)
├── images/ # Image assets (screenshots, product images)
└── README.md # Project documentation

---

## 💻 Technologies Used
| Feature        | Technology              |
|----------------|------------------------|
| Markup         | HTML5                  |
| Styling        | CSS3, Flexbox, Grid    |
| Interactivity  | Vanilla JavaScript     |
| Responsive UI  | Media Queries          |

## 🚀 Features
✔ Responsive layout for desktop and mobile  
✔ Hero banner with featured products  
✔ Product showcase section  
✔ Smooth transitions and hover effects  
✔ Newsletter subscription section  
✔ Modern glass/neon UI theme
